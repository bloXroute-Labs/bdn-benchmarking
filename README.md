# Public benchmarking scripts

> **DEPRECATION NOTICE:** The `python/` benchmarking scripts are deprecated and will no longer receive updates. Please use the Go-based tools in the `go/` directory instead; see `go/README.md` for installation and usage. For migration guidance and rationale, see `DEPRECATION.md`.

## Objective
This repo consists of scripts which can be used to compare performance of a node vs gateway.
There are two versions of the scripts:
- Python version (deprecated), detailed installation and usage instructions can be found [here](python/README.md).
- Go version, detailed installation and usage instructions can be found [here](go/README.md)
